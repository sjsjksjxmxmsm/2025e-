# 2025 电赛 E 题 · 简易自行瞄准装置（云台 + 激光）

STM32F103RCT6（江协 32 核心板 + 功能底板）驱动的两轴云台瞄准装置：K230 视觉模块检测矩形靶，
STM32 用 PD 闭环把激光笔打到靶心，并带陀螺仪转向前馈和随距离自适应的激光视差补偿。

## 硬件

| 部件 | 型号 | 接口 |
|---|---|---|
| 主控 | STM32F103RCT6（核心板 + 功能底板） | — |
| 云台 | 两轴 BLDC 云台 | USART1（PA9/PA10） |
| 视觉 | K230（CanMV） | USART3（PB11，DMA + IDLE） |
| 陀螺仪 | MPU6500 模块 | 软件 I2C（PB6/PB7） |
| 显示 | SH1106 OLED（4 线 SPI） | PB3/PB4/PB5 + PB8 |
| 输入 | 按键模块 | PC3 |

> 注意：云台 **2 号电机 = 底座/偏航（速度模式）**，**1 号电机 = 横臂/俯仰（多圈位置模式）**，
> 与手册默认顺序相反。偏航用速度模式，俯仰用多圈位置模式（发绝对角度）。

## 通信协议

**K230 → STM32**（8 字节定长）：

```
0x7B | xH xL | yH yL | areaH areaL | 0x7D
```

- `x = (uint16)x_u - 32768`，相对画面中心的像素偏移（右正）
- `area = area_u * 10`（**必须用 uint32 存，近距离会超过 65535**）

**STM32 → 云台电机**：

```
0x7A | ADDR | CMD | DATA... | BCC(异或) | 0x7B
```

## 关键实现

- **控制环**：TIM2 5 ms（200 Hz），视觉 35~38 fps。用帧号判断新数据，每拍都跑 PD。
- **瞄准点**：不是画面中心，而是「激光正好打中靶心时目标所在的位置」。
- **随距离自适应补偿**：目标面积 ∝ 1/距离²，偏移 ∝ 1/距离，故
  `偏移 = 常数项 + K × √面积`，两点标定即可解出。
- **陀螺前馈**：`补偿转速 = 角速度(°/s) / 6`（1 rpm = 6°/s）。
- **丢目标处理**：200 ms 迟滞 → 2 s 内用最后位置继续瞄准 → 再进入按键触发搜索。

## 调试中踩过的坑

1. **俯仰轴使能后不动**：多圈位置模式的「速度」参数必须非零，设 0 等于要求 0 速度走到目标。
2. **上万用表找不到引脚**：写引脚扫描程序，多个候选脚用不同占空比翻转，用平均电压区分。
3. **硬件 I2C 扫不到设备**：改用软件位翻转，同一组引脚立刻扫到 0x50 / 0x68。
4. **OLED 倒置且缺两列**：实际芯片是 SH1106 不是 SSD1306（132 列显存），列地址要 +2 偏移。
5. **上电俯仰轴猛甩**：多圈模式 0° 是电机绝对零点，需读实际角度做基准偏移 + 1 s 静默期。
6. **误差小的时候云台停住**：指令取整造成 ~50 px 死区，两轴都改成小数累加。
7. **脱靶后往反方向跑**：K230 丢目标发 (0,0)，覆盖了「最后位置」，改成只有有效目标帧才更新坐标。
8. **面积溢出**：`u16` 存不下 79500，改成 `u32`。
