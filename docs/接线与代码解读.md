# 2025 电赛 E 题（简易自行瞄准装置）—— F32C 工程代码解读 & 接线指南

> 工程：`25电赛E题_F32C_32版本`（Keil MDK，STM32F103C8T6，标准外设库 V3.5）
> 目标板代号 **F32C**（= STM32F103C8，48 脚，64KB Flash / 20KB RAM，晶振 8MHz，主频 72MHz）

---

## 0. 一句话概括

> **小车部分**：4 路红外看黑线 → 查表算出"转向差速" → 左右轮目标线速度 → 200Hz 增量式 PI → TIM1 PWM 驱动 TB6612 类双 H 桥；
> **云台部分**：视觉模块从串口丢来"目标相对画面中心的像素偏移" → 视觉 PD + IMU 偏航前馈 → 转成"一轴转速 / 二轴角度" → 串口协议发给两只云台电机。
> 全部实时控制在 **TIM2 的 5ms 中断**里跑，主循环 `while(1)` 只负责刷 OLED。

## 2. 程序怎么跑起来的

### 2.1 `main()` 初始化顺序（顺序有讲究）

```
MY_NVIC_PriorityGroupConfig(2)   中断分组
JTAG_Set(SWD_DISABLE) → JTAG_Set(SWD_ENABLE)   只留 SWD，释放 PB3/PB4/PA15
SysTick_Init(1000)               1ms 时基
OLED_Init()                      ★ 里面关 LSE / 关 TAMPER，PC13~PC15 才能当普通 IO
KEY_Init()
DataScope_DP_Init()              USART3 = 云台
BLDC_Disable/SetAcc/SetMode/Enable(1,2)   云台上电自检（每步间隔 500us）
IR_Track_Init()                  ★ 必须在 OLED_Init 之后
Bluetooth_USART2_Init()          USART2 = 视觉
MiniBalance_PWM_Init(7199,0)     TIM1 PWM 10kHz
Encoder_Init_TIM3/TIM4()
H30_IMU_Init()                   ★ 最后启动 TIM2，5ms 中断从此开始跑
while(1) { OLED_ShowMotorData(); }
```

> ⚠️ 两个顺序依赖：`OLED_Init()` 必须在 `IR_Track_Init()` 前（PC13/14/15 释放成普通 IO）；`H30_IMU_Init()` 放最后（它一开 TIM2，整个控制系统就活了）。

### 2.2 TIM2 中断时间线（每 5ms 一次，200Hz）

```
1. H30_IMU_TIM_Callback()        I2C 读 gyro_z（阻塞 ~0.4ms）
2. Vision_Frequency_Update()     每 200 帧统计一次视觉帧率(≈1s)
3. Key_Process()                 单击启停 / 长按换模式
4. Read_Encoder(4)/(3)           读 TIM4=左、TIM3=右 的计数并清零
5. Get_Velocity_From_Encoder()   计数 → m/s
6. IRDM_line_inspection()        红外状态机 → MotorA/B.Target_Encoder
7. Incremental_PI_Left/Right()   增量式 PI → PWM
8. Motor_SetPwm()                方向脚 + 占空比
9. 按路段改视觉中心/增益/前馈
10. Visual_Gimbal_Process()      视觉 PD + IMU 前馈 → 串口下发云台
```

> ⚠️ 第 1 步（I2C）+ 第 10 步（两次串口发送 7 字节 + 两次 `delay_us(250)`）合计约 **1.5~2ms**，占了 5ms 周期的 1/3。以后再往里加东西要小心——中断不能被拖长。

### 2.3 两种工作模式

| 模式 | 宏 | 行为 |
|---|---|---|
| 寻靶 `SEARCH` | `CONTROL_MODE_SEARCH`(1) | 车轮**强制停转**（`Motor_SetPwm` 直接清零）；云台：二轴先抬到 348°，一轴 24rpm 扫 2.5s（=360°，正好一圈），抓到目标就锁死 |
| 巡线打靶 `RUN` | `CONTROL_MODE_RUN`(0) | 红外循迹跑图 + 云台视觉瞄准 + IMU 前馈 |

按键（PA5，低电平按下）：
- **单击** → 当前模式 启动/停止（`Control_Work_Enable`）
- **长按** → 切换 SEARCH / RUN，并自动停机，需要再单击启动
- 双击 → 空实现

> 注意：`key.c` 注释按"10ms 扫一次"写，实际 5ms 扫一次，所以**长按约 1 秒**就触发（代码里 `Long_Press_count>200` × 5ms）。

## 3. 各模块关键细节

### 3.1 编码器 & 速度换算（`control.c`）

```c
MotorA.Current_Encoder = 计数 * 200Hz * 0.2042m
                       / (4倍频 * 13线 * 28减速比);
```
- 轮径：`WHEEL_PERIMETER=0.204203519` ≈ π×0.065（**65mm 轮**）
- 编码器：13 线 × 4 倍频 = 52，减速比 28 → 一圈轮子 **1456** 个计数
- 单位：**m/s**，量程约 ±0.6 m/s（`SPEED_MAX`）

### 3.2 速度环（增量式 PI）

```c
bias = target - actual;
pwm += Velocity_KP*(bias - last_bias) + Velocity_KI*bias;   // KP=400, KI=400
pwm 限幅 ±6900（ARR=7199 → 最大占空比 95.8%）
```
- 增量式的好处：天然带积分、不怕积分饱和；停机/寻靶模式自动清 `pwm` 和 `last_bias`
- **调参**：先 `KI=0` 调 `KP` 到"能跟上不抖"，再慢慢加 `KI` 消静差

### 3.3 红外循迹（`ir_track.c`）

4 路探头从左到右 → `dh1..dh4`，拼成一个 4 位码：`state = dh1<<3 | dh2<<2 | dh3<<1 | dh4`，**0 = 压黑线**。

| 状态码 | 含义 | 动作 |
|---|---|---|
| `0b1001`(9) | 只有最外两路压线 | 直行（`turn_diff=0`） |
| `0b1011`(11) / `0b1101`(13) | 偏一点 | ±`TurnMinAngle`(5) |
| `0b0111`(7) / `0b1110`(14) | 偏得多 | ±`TurnMaxAngle`(40) |
| `0b0001/0011` | 左侧直角 | +`Turn90Angle`(60) |
| `0b1000/1100` | 右侧直角 | −`Turn90Angle` |
| `0b1111`(15) | 全白丢线 | 沿用上一次的偏离方向 |
| `0b0000`(0) | 全黑 | 视为十字，直行 |

差速模型：
```c
base = BaseSpeed - BaseSpeed*|turn|/ForwardLimit   // 转得越狠越慢
left  = (base - turn) * 0.001f;      // mm/s → m/s
right = (base + turn) * 0.001f;
```
**直角弯流程**（`turn_cnt` 计数器，只在 RUN+使能时才会计数）：
`turn_cnt=1` → 0~100 tick（0.5s）**直冲 0.28m/s** → 100~562 tick 且没看到直线就**原地转**（左 −0.043 / 右 +0.043）→ 看到直线或超时(2.81s) 结束 → 切下一路段 + 平滑加速。

路段循环：`BA → AC → CD → DB → BA`，每过一个直角弯走一步（对应小题里绕 A/B/C/D 四点跑）。

直线/小偏差时会叠加陀螺仪修正：
```c
turn_diff += clamp(-gyro_z * 0.95, ±15);   // 抑制车体慢慢跑偏
```

### 3.4 视觉追踪（`control.c` 的 `Visual_Gimbal_Process`）

```
err_x = VISION_CENTER_X - g_follow_x;      // CENTER 是个位数，说明 g_follow_x 是"相对画面中心的像素偏移"
cmd_yaw  = VISION_DIR_X * gain * (KP*err_x + KD*diff_err_x);   KP=0.7 KD=0.02
cmd_pitch= VISION_DIR_Y * gain * (KP*err_y + KD*diff_err_y);   KP=0.25 KD=0.02
|err| < 3px 死区，输出置 0
yaw  限幅 ±30rpm，再加 IMU 前馈 -gyro_z/6（限幅 ±35），最终 ±100rpm
pitch 限幅 ±10（这个 10 不是 rpm，是"每 5ms 转 0.1°"→ 最大 200°/s）
```

二轴不是直接给角度，而是**积分**：
```c
Gimbal_Joint2_Target_Angle += pitch_cmd;      // 单位 0.1°，自动 0~3599 回绕
BLDC_SetSingleAngle(ADDR_2, 角度);
```
所以 pitch 这条链本质是"速度模式 + 软件积分成角度"。

**分段增益**（`TIM2_IRQHandler` 里按 `CurrentRoadSegment` 动态改）：

| 路段 | `vision_segment_gain` | `VISION_CENTER_X/Y` |
|---|---|---|
| SEARCH | 0.4 | −2 / 10 |
| 转弯中(100~500) | 0.6（AC/CD 段时 0.3） | 1 / 10（AC/CD 时 3/7） |
| BA | 0.8 | −4 / 8，带 `BA_VISION_FF` 前馈 |
| AC | `AC_VISION_K`=0.4 | 4 / 4 |
| CD | `CD_VISION_K`=0.4 | 1 / 7，带 `CD_VISION_FF` 前馈 |
| DB | `DB_VISION_K`=0.4 | 3 / 11 |

### 3.5 IMU（`h30_imu.c`）

- I2C1 **重映射到 PB8/PB9**，开漏，400kHz，从机地址 **0x6A**
- 寄存器：`0x10` 加速度 / `0x20` 陀螺 / `0x40` 欧拉 / `0x41` 四元数
- 每 5ms 只读陀螺 12 字节，取第 8~11 字节 = `gyro_z`，×1e-6
- 用途只有两处：循迹直线修正（`GyroStraightK`）、云台偏航前馈（`Gimbal_Yaw_Rpm_K=-1/6`）

### 3.6 串口协议

**① 视觉模块 → STM32（USART2，PA3，115200 8N1，只收）**
8 字节定长帧，DMA1_Channel6 自动收满即中断解析（不受数据里出现 0x7B/0x7D 影响）：

```
0x7B | XH XL | YH YL | AH AL | 0x7D
X = (int16)(XH<<8|XL) - 32768      目标相对画面中心的 x 偏移（像素）
Y = (int16)(YH<<8|YL) - 32768      目标相对画面中心的 y 偏移（像素）
A = (AH<<8|AL) × 10 → g_follow_area，固件只判"非 0 即有目标"
```
例：目标偏左 15px、偏下 8px → `7B 7F F1 80 08 00 78 7D`

**② STM32 → 云台（USART3，PB10/PB11，115200 8N1，两只电机共用一条总线，靠地址区分）**

```
0x7A | ADDR | CMD | DATA... | BCC | 0x7B     BCC = 前面所有字节异或
```
| CMD | 含义 | 说明 |
|---|---|---|
| `0x06` / `0x05` | 使能 / 失能 | |
| `0x00` | 设模式 | `0x0000` 速度；`0x0002` 单圈角度；`0x0004` 单圈角度(L) |
| `0x01` | 设速度 | int16 大端，rpm |
| `0x03` | 设单圈角度 | uint16 大端，0~3599（0.1°） |
| `0x07` | 设加速度 | 100 |
| `0x0E` | 读反馈 | 回 `7A ADDR TYPE D3 D2 D1 D0 BCC 7B` |

例：地址 1、速度 50rpm → `7A 01 01 00 32 48 7B`

### 4.1 引脚分配

| **左轮** PWM | **PA11** | TIM1_CH4 复用推挽 | 驱动器 `PWMB` |

| 左轮编码器 | **PB6 / PB7** | TIM4 CH1/CH2 浮空输入 | 左电机编码器 `A / B` |
| 红外 1（最左） | **PA2** | 上拉输入 | 循迹模块 `OUT1` |
| 红外 2 | **PC15** | 上拉输入 | `OUT2` |
| 红外 3 | **PC14** | 上拉输入 | `OUT3` |
| 红外 4（最右） | **PC13** | 上拉输入 | `OUT4` |

| IMU SCL | **PB8** | I2C1 重映射 开漏 | H30 `SCL` |
| IMU SDA | **PB9** | I2C1 重映射 开漏 | H30 `SDA` |

**注意**：PB3/PB4/PA15 被 OLED 占用 → 必须禁用 JTAG，代码里已经做了，**下载线只能用 SWD 四根线**，别用 20 针 JTAG。

### 4.2 分模块接法

**(1) 电机驱动（TB6612 / AT8870 类，A/B 双通道）**
```
VM  ← 电池 7.4~12V（和主控共地！）
VCC ← 3.3V
GND ← 电池负极 + 主控 GND
STBY← 3.3V（TB6612 必须拉高）
PWMA← PA8    AIN1← PB14   AIN2← PB15   AO1/AO2 ← 右电机
PWMB← PA11   BIN1← PB13   BIN2← PB12   BO1/BO2 ← 左电机
```
> `Motor_SetPwm()` 里是 **A 通道 = 右轮、B 通道 = 左轮**，别接反（接反了车会原地打转）。

**(2) 编码器电机（霍尔/光电，5 线：M+ M- VCC GND A B）**
```
电机线 → 驱动器 AO/BO
VCC    → 编码器供电（一般 5V，看电机规格）
GND    → 共地
A/B    → 左：PB6/PB7    右：PA6/PA7
```
- 编码器是**开漏输出**的话，代码里是浮空输入，需要外部 10k 上拉到 3.3V（或把 `encoder.c` 的 `GPIO_Mode_IN_FLOATING` 改成 `GPIO_Mode_IPU`）。
- 方向反了：改 `LEFT_ENCODER_SIGN` / `RIGHT_ENCODER_SIGN`（现在是 `1.0f`）。

**(3) 四路红外循迹**
```
VCC → 3.3V ★（不要接 5V！PC13/PC14/PC15 不是 5V 容忍引脚）
GND → GND
OUT1..OUT4 → PA2 / PC15 / PC14 / PC13（从左到右）
```
- 上电后 OLED 第一行 `IR xxxx`，手指遮住某个探头，对应位应从 1 变 0。
- 灵敏度用电位器调到"白底=1、黑线=0"。

**(4) OLED（0.96" SSD1306，7 针 SPI 版）**
```
GND VCC(3.3V) D0/SCL(PB5) D1/SDA(PB4) RES(PB3) DC(PB3?)  DC=PA15  CS=GND
```
- 代码是**软件 SPI 且没有 CS 控制**，所以 `CS` 必须接地（有的模块标 `CS`/`SS`，有的直接没有）。
- 若你的模块是 **I2C 四针版**，这套代码**不能直接用**（`OLED_WR_Byte` 是 SPI 时序），要么换 SPI 屏，要么改写驱动。

**(5) H30 IMU（I2C）**
```
VCC → 3.3V      GND → GND
SCL → PB8       SDA → PB9
```
- 模块上一般自带 4.7k 上拉；没有的话自己加。
- 地址 0x6A 固化在代码里，如果你的模块是 0x50/0x68，改 `H30_IMU_I2C_ADDR`。

**(6) 视觉模块（OpenMV / K230 / 树莓派等）**
```
5V  → 5V（独立稳压，别从板子 3.3V 取）
GND → 共地 ★
TX  → PA3（MCU 只收，不需要接 MCU 的 TX）
```
- 波特率 **115200 8N1**，8 字节帧（见 3.6）。
- OLED 第 4 行 `F xxx` 是帧率，正常应显示 20~60；显示 0 说明没收到或帧头/帧尾不对。

**(7) 二轴云台（F32C 无刷云台，两只电机级联在同一条串口总线上）**

《F32C二自由度云台使用手册》P7 默认：**X 轴电机 = 1 号，Y 轴电机 = 2 号**。
- **X 轴 = 下面底座那台**（竖装，绕垂直轴转）→ 水平旋转/**偏航** → 走 `MODE_SPEED` 速度模式
- **Y 轴 = 上面横臂那台**（横装，绕水平轴转）→ **俯仰** → 走 `MODE_SINGLE_POS_L` 单圈角度模式

> ⚠️ **本机实测与手册默认相反：2 号是 X 轴、1 号是 Y 轴。**
> 代码已用轴别名适配（`DataScope_DP.h`）：
> ```c
> #define BLDC_ADDR_X_AXIS    BLDC_ADDR_2   /* 偏航/速度模式 */
> #define BLDC_ADDR_Y_AXIS    BLDC_ADDR_1   /* 俯仰/单圈角度模式 */
> ```
> 业务代码一律用 `BLDC_ADDR_X_AXIS` / `BLDC_ADDR_Y_AXIS`，换电机只改这两行。

```
云台接口一（GH1.25-5P，X 轴电机侧面那个）:
  V+   ← 电池 8~15V（推荐 3S）
  GND  ← 共地 ★（TTL 串口必须共地）
  RX   ← PB10（USART3_TX）
  TX   → PB11（USART3_RX）
  3V3  ← 3.3V
```
- **只需要接 X 轴电机接口一这一根 5P 线**，Y 轴电机通过中间滑环级联，不用单独接线。
- ⚠️ 手册第 4 章的例程是接 **PA2/PA3（USART2）**，**本工程不能照抄**：PA2 已经给红外、PA3 给视觉模块，云台走的是 USART3 的 PB10/PB11。
- 接口二（MX1.25-4P，走滑环引到上层）线序：**1=RX 2=TX 3=GND 4=5V**。视觉模块（K230）装在云台上时，用这条路从滑环走线，可以防止绕线。
- 上电顺序：**先给云台上电 → 再给主控上电**（手册 P11 也是这么说的；代码上电就连发 `Disable/SetAcc/SetMode/Enable`，云台没起来会丢命令）。
- 手册限制：输入 8~15V，额定 0.4A / 最大 1.5A，**滑环最大 1A**，不支持热插拔，电源接反烧电机。
- 控制频率手册建议 100Hz、最大 200Hz；本工程 5ms = 200Hz，已经踩在上限。

### 4.3 电源树

```
电池 7.4~12V
 ├─ 电机驱动 VM（大电流）
 ├─ 云台电源（大电流，若 12V）
 └─ DC-DC 5V ─┬─ 视觉模块 5V
              └─ LDO 3.3V ─┬─ STM32 / OLED / IMU / 红外
                            └─ 电机编码器（若 3.3V 型）
所有 GND 必须连在一起（单点共地，避免电机电流串到信号地）
```

## 5. 上电 & 调试步骤（按顺序来，别一次全接）

1. **只接 SWD + OLED**：能烧进程序、屏幕亮、第一行显示 `IR 1111 M SEA E0` → OK。
2. **接按键**：单击 → `E` 变 1；长按 1s → `M` 在 `SEA/RUN` 之间切换（切换后会回到 `E0`）。
3. **接红外**：手指逐个遮挡，`IR` 后面 4 位随之变化，顺序对（左→右 = dh1→dh4）。
4. **接 IMU**：`GZ` 后面显示带一位小数的角速度，手拿板子快速左右转，数值应正负变化。
5. **接编码器（车架空！）**：手转轮子，OLED 第 2/3 行 `A` 显示 mm/s，向前推应为**正值**；两轮不一致就改 `*_ENCODER_SIGN`。
6. **接电机（车架空！）**：把 `Control_Work_Mode` 临时改成 `CONTROL_MODE_RUN`，单击启动，观察两轮转向是否与"目标速度正负"一致 → 不一致改 `LEFT_PWM_SIGN / RIGHT_PWM_SIGN`。
   > ★★ **PWM 符号和编码器符号必须同向**。如果电机转向反了但编码器是正的，PI 会变成正反馈，上电就是飞车。改符号后一定架空复测。
7. **接视觉**：看 `F` 帧率、`X/Y` 数值是否随目标移动。
8. **接云台（先别装车）**：上电后应看到云台先失能→设置→使能，进入 SEARCH 模式后一轴扫一圈、二轴抬到 348°；用手机测试视觉中心，云台应跟着转。
9. 最后整车落地，从低速 `BaseSpeed` 开始试。

## 6. 代码里我看到的坑（按优先级）

| # | 位置 | 问题 | 建议 |
